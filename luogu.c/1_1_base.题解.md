# 洛谷

## 习题1，a+=b

### 代码

```c
#include <stdio.h>

int main(){
    int T;
    scanf("%d", &T);
    while(T--){
        long long a, b, n, c = 0;
        scanf("%lld %lld %lld", &a, &b, &n);
        while(a <= n && b <= n){
            if(a < b){
                a += b;      // 谁小就把对方加上去,因为每次只可以执行一次操作，所以加最大的上数是最少的次数
            }else{
                b += a;
            }
            c++;
        }
        printf("%lld\n", c);
    }
    return 0;
}

```

### 题目

有三个整数 *a*，*b* 与 *n*，每一次可以执行以下操作之一：

- 将 *a* 增加 *b*；
- 将 *b* 增加 *a*。

求使得 *a* 和 *b* 中**至少**有一个数**严格大于** *n* **至少**需要操作几次。

## 输入格式

本题**含有多组数据**。第一行一个整数 *T*，表示数据组数。

接下来 *T* 行每行三个整数 *a*，*b* 与 *n*，含义如上所述。

## 输出格式

对于每组数据一行一个数，表示最小操作次数。

## 输入输出样例

**输入 #1**复制

```
2
1 2 3
5 4 100
```

**输出 #1**复制

```
2
7
```

## 说明/提示

- 1≤*T*≤100
- 1≤*a*,*b*≤*n*≤\(10^9\)

### 分析

操作之一：

- 将 *a* 增加 *b*；
- 将 *b* 增加 *a*。

求使得 *a* 和 *b* 中**至少**有一个数**严格大于** *n* **至少**需要操作几次。

根据这个可以得出，使用while循环，因为不知道是具体是几次循环，最小的次数就是加上的数一定是最大的，所以是小的数加大的数，每次只可以执行操作之一，是需要用ifelse判定一遍，来进行每次只加一次的作用。

根据输出输入样的样式，来决定\n,来打在哪里

最后就是a+b+n用int可能会溢出所以改用long long

### 知识点

1. 注意题目要求中的最小操作数和允许执行操作，因为刚开始写的时候没有if0else判定，就是因为觉得是一轮操作是可以干两个操作一起的所以一直跑不对

2. long long,因为如果a，b，n有可能会溢出来int的最大值是2*\(10^9\)，而long long不会这个大最大值9*\(10^18\)
